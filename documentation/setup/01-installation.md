# Installation

Run the automated installation script:

```bash
cd automation
./installation.sh
```

This script will:
- Install yay (AUR helper) if not already installed
- Install all pacman dependencies (fish, fastfetch, ranger, rofi, kitty, waybar, dunst, cava, cliphist, etc.)
- Install AUR applications (zen-browser, slack, devin, antigravity-ide, tidal-hifi, xwayland-satellite)
- Install Oh-My-Fish framework
- Install Rust toolchain

## Manual Setup

After running the installation script, follow the setup instructions in [setup.md](setup.md) to configure your system.
